# Data Analyst

This repository contains my data analysis projects and work.

## Projects

- **Sales Predict** — Linear regression model that predicts product sales from TV, Radio, and Newspaper advertising spend. Built with pandas, scikit-learn, matplotlib, and seaborn.

## Skills

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## How to run a notebook

1. Put the required dataset (`.csv`) in the same folder as the notebook
2. Open the notebook in Jupyter Notebook / JupyterLab / VS Code
3. Run all cells
