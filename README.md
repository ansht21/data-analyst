## Projects

### 1. Sales Predict — Advertising Spend → Sales (this repo)
Linear regression model predicting product sales from TV, Radio, Newspaper spend. Built with pandas, scikit-learn, matplotlib, seaborn.

### 2. Supply Chain Performance — 7,991 orders · 47 SKUs
$73.0M net revenue / $21.2M profit. Proved late delivery is systemic (only 0.08% variance between warehouses). ABC classification + 10-chart Excel dashboard.
→ Full code: `ansht120/data-analytics-projects`

### 3. Uber Trip Demand — 35,000 trips
5–7 PM = 31.2% of demand; airport = 39.6% volume but 54.8% revenue. SARIMA forecast, K-Means clustering, Random Forest fare predictor (R² 0.972).

### 4. Subscription Retention — 7,032 customers
26.6% churn; month-to-month + fiber = 72% revenue at risk. LogReg AUC 0.839. Interactive Excel dashboard + SQL cohort analysis.

## How to run a notebook

1. Put the required dataset (`.csv`) in the same folder as the notebook
2. Open the notebook in Jupyter / JupyterLab / VS Code
3. Run all cells
4. Install deps if needed: `pip install pandas numpy matplotlib seaborn scikit-learn openpyxl`
